## 2. Platform Protection Matrix & Behavior

| Target Platform | Screenshot Prevention Mechanism | Screen Recording Prevention / Detection | Fallback / Deterrent Controls | Protection Status |
| :--- | :--- | :--- | :--- | :--- |
| **Windows Desktop** | OS Native Hardware Exclude (`SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`) | OS Hardware Excluded (Black / Invisible window in captures) | Dynamic Watermark + Expiring Tokens | **IMPLEMENTED** |
| **Android Phone/Tablet** | OS Hardware Secure Window (`WindowManager.LayoutParams.FLAG_SECURE`) | OS Hardware Blocked (Black view in recents & recordings) + Android 14 Capture Callback | App Switcher Obscure + Dynamic Watermark | **IMPLEMENTED** |
| **iPhone / iPad** | Detection via `UIScreen.capturedDidChangeNotification` & `userDidTakeScreenshotNotification` | Screen Recording Detected -> `CaptureBlockedOverlay` displayed | App Switcher Blur + Dynamic Watermark | **IMPLEMENTED** |
| **macOS** | Native Display Sharing Restriction (`window.sharingType = .none`) | Excluded from macOS Screen Recording & Window Capture APIs | App Switcher Obscure + Dynamic Watermark | **IMPLEMENTED** |
| **Linux Desktop** | Best-effort compositor window privacy hint & MethodChannel | Dynamic Watermark + Expiring Asset Tokens + Obscuring | Dynamic Watermark + Anti-Scraping | **IMPLEMENTED** |
| **Web Browsers** | Browser Context Menu Disable + Drag Start Block + Copy/Print Shortcut Prevention | Browser Visibility Change Obscure (`visibilitychange`) | Short-lived Signed URLs + Dynamic Watermark + Cloudflare Anti-Bot | **IMPLEMENTED** |

## 3. Backend & Storage Security

1. **Private Buckets**:
   Both `magazine_pages` and `wildlife_gallery` storage buckets are set to `public = false`.
2. **Short-Lived Signed URLs**:
   Original assets are accessed exclusively via 120-second signed tokens generated by `ProtectedAssetService`.
3. **Session & Security Event Auditing**:
   Active protection sessions and security events (e.g. screenshot attempts, recording detections) are logged to Supabase `protection_sessions` and `protection_security_events` tables without collecting PII.

---

## 4. Cloudflare & Anti-Scraping Architecture

- Refer to `docs/CLOUDFLARE_PROTECTION.md` for exact Cloudflare dashboard settings.
- **Key Rules**:
  - Rate limiting on `/storage/v1/object/sign/` (max 60 requests/min).
  - Hotlink prevention blocking external referers.
  - Bypass Edge Cache for signed token URLs.

## 5. Deployment & Manual Verification Checklist

### Windows:
- [x] Test `Win + Shift + S`: Captured area excludes app window or displays black rectangle.
- [x] Test Snipping Tool & PrintScreen: Window excluded from capture.
- [x] Test OBS / Game Bar Recording: App window rendered invisible/black in recording.

### Android:
- [x] Test Hardware Screenshot (`Power + Vol Down`): "Taking screenshots isn't allowed by the app".
- [x] Test Screen Recorder: Screen recording produces black video.
- [x] Test App Switcher: Recents preview is obscured/blank.

### iOS / iPadOS:
- [x] Test Screen Recording: When active, app displays `CaptureBlockedOverlay`.
- [x] Test App Switcher: App blurs in background/switcher.

### macOS:
- [x] Test Cmd+Shift+4: Window excluded from screen capture via `sharingType = .none`.

### Web Browsers:
- [x] Test Right Click: Context menu disabled.
- [x] Test Image Drag: Dragging images disabled.
- [x] Test Shortcuts: Ctrl+P, Ctrl+S, F12 prevented.
- [x] Test Tab Switch: View obscured when tab loses focus.
